**[GitHub Copilot CLI](https://docs.github.com/copilot/concepts/agents/about-copilot-cli)** を使うと、ターミナルで GitHub Copilot をエージェント型コーディング アシスタントとして利用できます。コードベースを調べ、コードを生成し、コマンドを実行し、外部ツールに接続できます。すべてコマンド ラインで行えるため、グラフィカル エディターに切り替えずに作業を続けられます。

このワークショップでは、Copilot CLI のインストールと認証から始めます。次に、Tailspin Toys で 2 つの変更を行います。星評価を表示し、レビュー後に最初のプル リクエスト (PR) を手動でマージします。その後、Issue から絞り込み機能を計画し、実装してレビューします。カスタム命令でコードを導き、`quality-checks` スキルを更新し、Playwright MCP でブラウザー上の動作を確認して、品質保証 (QA) エージェントで要件と検証結果をレビューします。最後に、Agent Merge を使って機能 PR をマージし、コンテキスト、モデル、共有に使う slash command を確認します。また、オプションの[Foundry シリーズ][foundry]では、モデルを準備し、カタログ情報に基づく Backer Concierge を構築してデプロイし、Web サイトに接続できます。

## 前提条件

このワークショップに参加する前に、次のものを準備してください。

- [ ] **Copilot Student、Pro、Pro+、Business、Enterprise** のいずれかが有効な GitHub アカウント
- [ ] リポジトリと Codespace を作成する権限
- [ ] ターミナルまたはコマンド ライン操作の基本的な知識

> [!TIP]
> 有料プランがありませんか。認証済みの学生は [GitHub Education][student-plan] を通じて GitHub Copilot を無料で利用できます。**Copilot Student** プランには、このワークショップで使うエージェント、MCP、コード レビュー、Copilot CLI の機能が含まれます。

> [!NOTE]
> Copilot Business または Copilot Enterprise を使う場合は、管理者が Copilot CLI を有効にしていることを確認してください。
